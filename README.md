# Apex Entertainment Corp. — GitHub Pages Roleplay

## Publish it
1. Create a GitHub repository (for example `apex-entertainment-roleplay`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Open the published URL after GitHub finishes deploying.

## Roleplay sign-in
- Developer username: `Apex Entertainment Consoles`
- Developer passcode: `ApexStatRoom`
- Any other username becomes a community account; community accounts only see Dashboard, Live Inbox, and Horizon Plus.

## Important limitations
This is a static browser-only simulation. It saves state in the current browser using localStorage; it does not synchronize between different users/devices. Developer credentials are visible in client-side source code and are for roleplay only, not real security. Gmail, subscriptions, finances, bans, hiring, and company data are simulated. Conference speech output uses browser speech synthesis when available; this version can record microphone audio if permitted, but it does not include reliable speech-to-text or an AI backend.
