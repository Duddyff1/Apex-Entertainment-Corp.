# Apex Entertainment Corp. — Roleplay Website

This is a fictional company roleplay site made for GitHub Pages. It does not connect to real email, payment, shipping, or company services.

## Publish on GitHub Pages
1. Upload `index.html` to the root of your repository (replace the existing file).
2. Commit the change.
3. In repository Settings → Pages, select the publishing branch/folder if it is not already configured.

## Included features
- Executive dashboard, console lab, game portfolio, employees, hiring, bans, moderators, Apex Gmail, conference room, and community inbox.
- Gmail roleplay responses arrive after a simulated delay instead of instantly. Conference participants pause before replying.
- Apex Game Studio accepts a written game idea, generates starter HTML/JavaScript, previews a playable browser prototype, and can save it to the Games Portfolio. The local builder uses simple keyword-based templates; it is not a full AI coding service.
- Data is stored in the current browser's local storage. Different devices do not automatically share updates.
- Any giveaway addresses and company metrics are fictional roleplay data. Never enter real private information.
